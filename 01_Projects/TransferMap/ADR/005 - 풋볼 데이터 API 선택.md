# ADR 005 — 풋볼 외부 데이터 API 선택

## 문제

Fixtures, Standings, Match Detail, Injury, Stadium 기능 구현을 위해 외부 데이터 소스가 필요하다. 단일 API로 커버할지, 소스를 분산할지 결정이 필요하다.

## 선택지 비교

| API | 무료 한도 | Fixtures | Standings | Injuries | Lineups/Events | Stadium |
|-----|----------|----------|-----------|----------|----------------|---------|
| **API-Football** | 100 req/day | ✅ | ✅ | ✅ | ✅ | ✅ |
| **football-data.org** | 10 req/min | ✅ | ✅ | ❌ | ❌ (유료) | ❌ |
| TheSportsDB | 3 req/sec | 제한적 | ❌ | ❌ | ❌ | ✅ 이미지 |
| OpenLigaDB | 무제한 | Bundesliga만 | Bundesliga만 | ❌ | ❌ | ❌ |

## 현재 구현 상태 (2026-05-21)

- `ApiFootballConfig` — 헤더 `X-Auth-Token` (football-data.org 방식)
- `ApiFootballProperties` — baseUrl `https://api.football-data.org/v4`
- `FixturesServiceImpl` — 파서 전면 교체 완료
- 리그 코드: 숫자 ID → 문자 코드 (`PL`, `PD`, `BL1`, `SA`, `FL1`)
- `getMatchEvents`, `getMatchStats`, `getMatchLineups` → 빈 응답 반환 (8월 복원 예정)

### 캐싱 전략 (현재 유지)

```
fixtures:{leagueId}:{date}        TTL 5분
standings:{leagueId}:{season}     TTL 1시간
```
