## 30: Gesture 확장 (WorldMap → CountryMapPage)

- `WorldMap`의 터치 제스처 로직을 `useMapGesture` 훅으로 추출
- `CountryMapPage`에 동일 훅 적용
- 제스처: pinch zoom, pan, 더블탭 reset
- 추출 인터페이스:
  ```ts
  useMapGesture(svgRef, { onZoom, onPan, onReset })
  ```

## 31: Fixtures Schedule — `/fixtures`

### 레이아웃
```
[리그 탭: EPL | La Liga | Bundesliga | Serie A | Ligue 1]
[날짜 네비게이터: ← 2025-05-10 · 2025-05-11 · 오늘 · 2025-05-13 →]

[경기 카드 목록]
  ┌─────────────────────────────────┐
  │  18:30  맨시티  2 - 1  첼시    │
  │  FT     로고         로고       │
  │  Etihad Stadium                │
  └─────────────────────────────────┘
  ┌─────────────────────────────────┐
  │  21:00  아스날  vs  토트넘      │
  │  예정   로고         로고       │
  └─────────────────────────────────┘
```

### 컴포넌트
- `FixturesPage` — 라우트 컨테이너
- `LeagueTabBar` — 리그 탭 (기존 LeagueFilter 재사용 검토)
- `DateNavigator` — 날짜 슬라이더
- `MatchCard` — 단일 경기 카드 (결과/예정 상태 구분)

### 상태 배지
- `FT` — 종료 (흰색)
- `LIVE` — 진행 중 (빨간색 점 + 경과 시간)
- `NS` — 예정 (회색)
- `PST` — 연기 (주황색)

### 라우팅
- `/fixtures` → 오늘 날짜 기본
- 경기 카드 클릭 → `/fixtures/:fixtureId` (Match Detail)

## 33: Match Detail — `/fixtures/:fixtureId`

### 레이아웃
```
[헤더: 홈팀 로고 · 2-1 · 원정팀 로고]
[부제: 리그 · 날짜 · 경기장]

[탭: 라인업 | 이벤트 | 통계]

── 라인업 탭 ──
  [홈 포메이션 4-3-3]      [원정 포메이션 4-2-3-1]
  ┌──────────────────────────────────┐
  │  [피치 SVG]                     │
  │  선수 마커 포지션 배치            │
  └──────────────────────────────────┘
  교체 선수 목록

── 이벤트 탭 ──
  12' ⚽ 홀란드 (어시스트: 데브라위너)
  34' 🟨 살라 (파울)
  67' 🔄 손흥민 → 리샤를리송

── 통계 탭 ──
  점유율      62% ██████░░░░ 38%
  유효슈팅    8  ████░░░░░░  4
  패스 정확도 89% ████████░░ 83%
```

### 렌더링 전략 (ISO 분리)
- `React.lazy` + Suspense로 Match Detail 청크 분리
- 피치 SVG는 독립 컴포넌트 (`PitchLayout`) — `WorldMap`과 D3 공유 안 함
- 라인업 그리드: CSS grid + 절대 위치 (D3 불필요)

## 25–27: Stadium (구단 상세 패널 확장)

### 기존 구단 상세 패널에 추가
```
구단 상세 패널
  ├── 기존: Incoming / Outgoing 탭
  └── 추가: Stadium 탭
        ┌────────────────────────────┐
        │ [경기장 이미지]             │
        │ 알리안츠 아레나             │
        │ 수용인원: 75,000명         │
        │ 위치: 뮌헨, 독일           │
        └────────────────────────────┘
```

### 지도 레이어 (선택적)
- 경기장 핀 마커 (구단 마커와 구분 — 다른 아이콘)
- 토글 버튼으로 on/off
