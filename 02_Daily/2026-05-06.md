## 오늘 한 일

### 루머 확정 로직 구현
- `PATCH /api/admin/news/{newsId}/confirm` — Verification upsert + Player.currentClub 동기화
- `X-Admin-Token` 헤더로 Admin 인증 (기존 AdminInterceptor 재사용)

### Report 개선
- confidence 필드 BE/FE 전체 제거
- 보고서 제목 `[시즌] 제목` 형식으로 변경
- 개별 보고서 `/report/:id` URL 부여 → AdSense 복제/가치 없음 해결
- 보고서별 고유 `<Helmet>` (title, description, canonical)

### Sitemap
- `sitemap-main.xml` HTML 반환 문제 수정 (Nginx `.xml` 명시적 처리)
- `sitemap-players.xml` Nginx 프록시 수정 (FE nginx.conf에 누락돼 있었음)
- `sitemap-reports.xml` 추가 (BE 엔드포인트 + Nginx 프록시 + sitemap.xml 인덱스)

### 기타
- GlobalExceptionHandler 로깅 추가 (`log.error` — 기존에 500 원인 파악 불가 문제 해결)
- CORS PATCH 메서드 추가
