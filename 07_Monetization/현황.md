### 무한스크롤 광고 — AdFit vs AdSense

현재 AdFit은 **unit ID당 페이지 1회 노출 제한**이 있어서 뉴스피드 3개마다 광고를 넣어도 등록된 unit 개수만큼만 표시됨 (unit 3개 → 광고 최대 3개).

AdSense는 각 `<ins>` 요소가 독립적으로 `adsbygoogle.push({})`를 호출하는 방식이라 **같은 slot ID로 무제한 반복 삽입 가능**. 무한스크롤에 적합.

AdSense 전환 시 `AdSlot.tsx` 구현 변경 필요:
```tsx
useEffect(() => {
  (window.adsbygoogle = window.adsbygoogle || []).push({});
}, []);
```
unit ID를 여러 개 만들 필요 없이 slot ID 하나로 피드 전체 커버 가능.
