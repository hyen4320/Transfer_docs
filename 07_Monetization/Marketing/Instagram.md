# Instagram 릴스 홍보 전략

## 영상 구조

```
[0~7초] 후킹 클립  →  [7초~끝] 홍보 영상
```

---

## 후킹 클립 (0~7초)

릴스는 **첫 3초에 스크롤을 멈춰야** 한다.

**효과적인 방식**
- 충격적인 숫자/통계 텍스트 — "이 선수 이적료 실화임?"
- 밈/트렌드 영상 위에 텍스트 오버레이
- 논란/궁금증 유발 — "축구팬이라면 이거 몰랐을 걸"
- 빠른 컷 편집 + 강한 BGM

**소재 찾기**
- 유튜브/틱톡 트렌드 영상 (저작권 주의 — 직접 재창작 권장)
- Pexels, Pixabay 무료 축구 클립
- 실제 이적 뉴스 스크린샷 활용

---

## 편집 흐름

```
후킹 클립 (트렌디한 BGM)
    ↓ 전환 효과 (줌인, 컷, 화면 전환)
홍보 영상 (사이트 화면 + 핵심 기능 소개)
    ↓
CTA — "링크 바이오 확인" or "팔로우"
```

---

## 추천 툴

| 단계 | 툴 |
|---|---|
| 후킹 소재 편집 | CapCut (자동 자막, 트렌드 효과 내장) |
| 화면 녹화 | OBS or Windows 기본 녹화 (Win+G) |
| BGM | CapCut 내장 무료 음악 |
| 업로드 | Instagram 릴스 직접 (9:16 비율) |

---

## 핵심 팁

- **9:16 세로 비율** 필수 (1080x1920)
- 자막은 **가운데~상단** 배치 (하단은 UI에 가림)
- 후킹~본 영상 전환 시 **BGM 볼륨 자연스럽게 낮추기**
- 전체 길이 **30~45초** 이내가 릴스 알고리즘에 유리
