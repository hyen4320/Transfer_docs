# X (트위터) 마케팅 전략

## 플랫폼 특성

- **실시간성** — 이적 루머/확정 소식이 가장 빠르게 퍼지는 플랫폼
- **텍스트 중심** — 이미지/영상 없어도 확산 가능
- **리트윗 구조** — 바이럴 확산이 타 플랫폼보다 빠름
- **축구 커뮤니티 활성** — #EPL #SerieA #분데스리가 등 해시태그 문화 강함

---

## 콘텐츠 유형

### 1. 이적 속보 트윗
```
[속보] 손흥민 → PSG 이적 협상 시작
계약 기간 2년 + 옵션 1년
이적료 €45M 추산

전체 분석 → transfermap.site
```
- 짧고 명확하게
- 링크는 맨 아래
- 이모지 대신 [ ] 괄호로 강조

### 2. 통계/인포그래픽 이미지
- 선수 이적 히스토리 카드
- 클럽별 이적 지출 순위
- 시즌 이적 시장 요약

### 3. 스레드 (Thread)
- "올여름 이적시장 총정리 (1/10)" 형식
- 각 트윗마다 핵심 1가지
- 마지막 트윗에 사이트 링크 CTA

### 4. 질문/투표 (Poll)
- "손흥민의 다음 클럽은?" 투표
- 참여 유도 → 알고리즘 노출 증가

---

## 후킹 전략

**첫 줄이 전부다** — 타임라인에서 첫 줄만 보임

| 유형 | 예시 |
|---|---|
| 숫자 | "이적료 €200M, 역대 3위" |
| 의문 | "이 이적이 성사되면 리그가 바뀐다" |
| 반전 | "망한 줄 알았던 이적, 1년 후 결과" |
| 속보 | "[확인됨] ○○ → ○○ 이적 공식 발표" |

---

## 해시태그 전략

- 게시글당 **2~3개** 이내 (과도하면 스팸 처리)
- 시즌 중: `#이적시장` `#EPL` `#UCL`
- 이적 윈도우: `#TransferNews` `#TransferWindow`
- 한국 선수 관련: `#손흥민` `#이강인`

---

## 계정 운영 팁

- **업로드 시간** — 경기 직후 (밤 10시~자정), 오전 8~9시
- **빈도** — 하루 3~5개 (너무 많으면 언팔 유발)
- **팔로우 전략** — 축구 기자, 이적 전문 계정 팔로우 → 노출 증가
- **인용 트윗** — 유명 계정 트윗 인용하여 내 분석 추가
- **리플 마케팅** — 유명 축구 계정 게시물에 빠른 댓글 달기

---

## 사이트 유입 전략

- 프로필 바이오에 사이트 링크 고정
- 스레드 마지막에 항상 "전체 보기 → [링크]"
- 이미지 카드에 URL 워터마크 삽입
- 링크트리 대신 직접 URL 사용 (X 알고리즘이 외부 링크 억제 — 댓글에 링크 다는 방법도 유효)
