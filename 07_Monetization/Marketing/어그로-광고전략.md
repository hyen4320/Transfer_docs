# 어그로 → 서비스 광고 전략

## 핵심 구조

```
[어그로 주제]  →  [정보/콘텐츠 본문]  →  [자연스러운 연결]  →  [서비스 CTA]
```

광고처럼 보이면 즉시 스크롤 넘김 — **콘텐츠처럼 보이면서 광고**가 목표

---

## 전략 원칙

1. **어그로는 주제로, 광고는 결말로** — 본문에서 절대 광고하지 않음
2. **자연스러운 연결** — "이걸 한눈에 보고 싶어서 직접 만들었다" 식의 흐름
3. **가치 먼저** — 서비스 언급 전에 충분한 정보를 먼저 줘야 거부감 없음
4. **플랫폼별 톤 분리** — X는 텍스트 날카롭게, 인스타는 시각적으로, 릴스는 빠르게

---

## 어그로 주제 목록

### 논란/충격 계열
- "역대 최악의 이적 TOP 5 (이적료 낭비 실화)"
- "이 선수 이적시키면 안 됐던 이유"
- "€1억 넘게 쓰고 강등된 클럽들"
- "바르사가 망한 진짜 이유는 이적 시장이었다"
- "PSG가 슈퍼스타를 사도 우승 못 하는 이유"

### 궁금증/반전 계열
- "이적료 €0인데 왜 이게 역대 최고 이적일까"
- "실패한 줄 알았던 이적, 3년 후 결과"
- "아무도 몰랐던 이적 루머가 현실이 된 순간들"
- "이 선수 어디 갔는지 아는 사람?"
- "무명 선수였는데 €100M에 팔린 이유"

### 통계/데이터 계열
- "지난 10년간 이적료 TOP 10, 근데 성공한 건?"
- "빅클럽 이적 성공률 데이터로 분석해봄"
- "EPL vs 라리가 이적 지출 비교 (2015~2025)"
- "이적 시장에서 가장 돈 잘 쓴 클럽 vs 못 쓴 클럽"
- "한국 선수 유럽 이적 역사 전부 정리"

### 시즌/타이밍 계열 (이적 윈도우 맞춰서)
- "이번 여름 이적 시장 터질 것 같은 딜 5개"
- "마감일 자정에 성사된 충격 이적들"
- "이번 겨울 이적 시장 총정리 (진짜 다 있음)"
- "지금 이적 협상 중인 선수들 모아봄"

### 한국 선수 특화 (국내 유입용)
- "손흥민 이적 루머 나올 때마다 모아봤다"
- "이강인 PSG 이적 1년 후 진짜 평가"
- "유럽 간 한국 선수들 지금 어디 있나"
- "한국 선수 역대 최고 이적료 순위"

## 플랫폼별 실행 방법

### X (트위터)

**형식**
```
[어그로 제목 — 첫 줄이 전부]

본문: 3~5개 핵심 정보 나열
(충분히 흥미롭게)

근데 이걸 지도로 한눈에 볼 수 있게
직접 만들어봤음 → transfermap.site
```

**팁**
- 스레드로 뽑으면 체류 시간 늘어나 알고리즘 유리
- 마지막 트윗에만 링크 (중간에 넣으면 억제됨)
- 인용 트윗으로 기존 바이럴 콘텐츠에 올라타기

---

### Instagram 릴스

**구조 (30~45초)**
```
0~7초  : 어그로 텍스트 + 강한 BGM ("이 이적 실화임?")
7~25초 : 핵심 정보 빠른 컷 편집
25~35초: "근데 이거 한눈에 볼 수 있는 사이트 만들었음"
35~45초: 사이트 화면 데모 + "링크 바이오에"
```

**팁**
- 텍스트 자막 필수 (소리 끄고 보는 사람 많음)
- 어그로 클립은 Pexels 무료 축구 영상 활용
- 전환 구간에서 BGM 볼륨 자연스럽게 낮추기

---

### Instagram 카드/피드

**구조 (슬라이드 5~7장)**
```
1장: 어그로 제목 (크게)
2~5장: 정보 본문 (장당 1가지)
6장: "이걸 지도로 보고 싶어서 만들었음"
7장: 사이트 스크린샷 + URL
```

## 자연스러운 연결 문구 예시

광고티 나지 않게 자연스럽게 이어주는 게 핵심

- "이걸 한눈에 보고 싶어서 직접 만들어봤음"
- "데이터 찾다가 없어서 내가 만들었다"
- "이런 정보 한 곳에 모은 곳이 없길래"
- "축구팬으로서 답답해서 직접 만든 사이트"
- "더 궁금하면 내가 만든 이적 지도에서 확인 가능"

## 밈 바이트-앤-스위치 전략 (축구 무관 → TransferMap 피벗)

축구와 전혀 관련 없는 주제로 어그로를 끈 뒤, 마지막에 뜬금없이 TransferMap으로 트는 방식.
웃기면 공유되고, 공유되면 알고리즘이 태움.

### 핵심 공식

```
[완전 뜬금없는 주제]  →  [진지하게 전개]  →  [갑자기 TransferMap으로 전환]
```

전환 순간의 **낙차**가 클수록 밈으로 퍼질 가능성 높아짐

---

### 주제 + 피벗 예시

**일상/사회 계열**
- "요즘 월세 너무 오르지 않음? 근데 이적료에 비하면..." → TransferMap
- "취업 준비하면서 느낀 건데, 선수들은 이적할 때 이력서 같은 거 안 써도 됨" → TransferMap
- "짜장면 vs 짬뽕 고민하다가 결국 둘 다 시킴 — 근데 빅클럽들도 이런 식으로 선수 삼" → TransferMap
- "요즘 날씨 미치겠다 진짜 — 근데 이적 시장도 미쳐가고 있음" → TransferMap

**밈/트렌드 계열**
- 유행하는 밈 포맷 그대로 쓰고 마지막 칸만 TransferMap로 교체
- "이거 실화냐" 밈 → 마지막에 이적료 데이터 보여주며 TransferMap
- "POV: 네가 빅클럽 단장임" 포맷 → 결말에 TransferMap

**영화/드라마 계열**
- "오징어게임처럼 탈락하면 퇴출되는 이적 시장 — 데이터로 봤음" → TransferMap
- "어벤져스 어셈블 근데 축구 이적 버전" → TransferMap
- "인터스텔라 보고 나서 이적 루머 보니까 현실이 더 SF임" → TransferMap

**음식/일상 계열**
- "편의점 삼각김밥 먹다가 문득 — 이 선수 어디 갔지?" → TransferMap
- "배달 앱 켰다가 닫았다가 반복 — 이적 협상이 딱 이럼" → TransferMap

**시험/공부 계열**
- "수능 다 틀렸다고 인생 끝나는 거 아님 — 이적 실패해도 대박 난 선수들" → TransferMap
- "GPT한테 공부 물어보다가 이적 데이터 물어봤는데 틀림 — 그래서 직접 만들었음" → TransferMap

---

### 릴스 연출법

```
0~5초  : 완전 뜬금없는 장면/텍스트 (음식, 날씨, 일상 등)
5~15초 : 진지하게 전개 (시청자는 이게 뭔 영상인지 모름)
15~20초: 갑자기 전환 — "근데 갑자기 TransferMap 얘기 해도 됨?"
20~35초: TransferMap 화면 데모
35초~  : "링크 바이오에" or 그냥 끝내도 됨 (여운이 더 강할 수 있음)
```

BGM은 전환 직전까지 원래 분위기 유지 → 전환 순간에 갑자기 축구 관련 BGM or 효과음

### 추가 포맷

**댓글 유도형**
본문에서 완전 뜬금없는 질문을 던지고 댓글 폭발로 알고리즘을 탄 뒤, 답글에서 서비스 연결
```
"짜장 vs 짬뽕 댓글로 알려줘"
(댓글 폭발 → 알고리즘 노출 증가)
→ 인기 답글에 "그나저나 이적 시장도 이런 고민 있음 → transfermap.site"
```
- X 스레드 / 릴스 댓글 둘 다 적용 가능
- 질문은 간단할수록 참여율 높음

---

**시리즈 떡밥형**
1편에서 일부러 정보를 끊고 팔로우를 유도, 2편 마지막에 서비스 연결
```
1편: "유럽 이적 시장에서 가장 말도 안 되는 딜 5개 (1~3위)"
     → 마지막에 "4, 5위는 다음 편에"
2편: 4, 5위 공개
     → 마지막에 "전체 이적 데이터 보고 싶으면 → transfermap.site"
```
- 팔로우 전환율이 다른 포맷보다 높음
- 1편 반응 보고 2편 발행 여부 결정 가능

---

**챌린지 편승형**
유행하는 릴스/틱톡 챌린지 포맷을 그대로 따라하되, 마지막 컷만 TransferMap 화면으로 교체
- 트렌드 파악은 틱톡 탐색 탭 / X 실시간 트렌드로
- 포맷 자체가 이미 바이럴 검증된 상태라 진입 장벽 낮음
- 타이밍이 핵심 — 챌린지 유행 시작 후 3일 이내에 올려야 알고리즘 탐

---

**반응 영상형**
다른 사람의 이적 관련 영상/게시물에 리액션하는 척 하다가 자연스럽게 피벗
```
"이 영상 보다가 데이터가 틀린 것 같아서 직접 찾아봤음"
→ TransferMap 화면에서 정확한 수치 보여주기
→ "이런 거 정리된 데이터 없길래 직접 만들었음"
```
- 원본 영상 인용/반응 구조라 신뢰도 있어 보임
- 원본 계정 멘션하면 노출 추가로 늘어날 수 있음

---

### 주의사항

- 전환이 너무 억지스러우면 욕먹음 — 약간의 **논리적 연결고리**는 있어야 함 (아주 얇아도 됨)
- 같은 포맷 반복하면 식상해짐 — 주제는 매번 바꾸되 구조는 유지
- 댓글 반응 보고 잘 먹히는 연결고리 패턴 파악 후 재활용

---

## 주의사항

- 제목은 자극적이되 **거짓 정보 금지** — 신뢰 잃으면 회복 불가
- CTA는 **1개만** — 링크, 팔로우, 댓글 동시에 요구하지 말 것
- 매번 같은 포맷 반복하면 광고로 인식됨 — 주기적으로 형식 변경
