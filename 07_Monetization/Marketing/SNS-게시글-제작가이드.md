# SNS 게시글 기획 & 제작 가이드

transfer-map.com 기준. 이적 뉴스/루머 지도 서비스.

---

## 기획 — 공통 원칙

### 언제 올릴까
- **이적 확정 속보** — 가장 높은 반응. 확정 직후 30분 이내 올려야 의미 있음.
- **루머 집중 기간** — 여름(6~8월), 겨울(1월) 이적 시장. 이 시기에 활동량 극대화.
- **비시즌** — 주 1~2회 정도 맵 근황 공유 수준으로 유지. 너무 조용하면 팔로워 이탈.

### 소재 선택 기준
1. 화제성 높은 선수 이적 (빅클럽 ↔ 빅클럽, 큰 이적료)
2. 맵에서 경로가 시각적으로 임팩트 있는 건 (장거리 이적, 리그 간 이동)
3. 여러 루머가 한 선수에 몰린 경우 (지도 위 다중 화살표 → 시각적으로 흥미)

## 제작 단계 — 플랫폼별

### Instagram

#### 스텝

1. **스크린샷 캡처**
   - 데스크탑 브라우저에서 캡처 (모바일 아님 — 지도 해상도 중요)
   - 해당 이적 경로가 화면 중앙에 오도록 맵 위치 조정
   - 확대 레벨: 이적 출발-도착 클럽이 모두 보이는 정도
   - 가능하면 이적 화살표가 선명하게 보이는 상태에서 캡처

2. **캡션 작성**
   ```
   [선수명] from [출발 클럽] to [도착 클럽] 🔴 Confirmed / 🟡 Rumor
   
   Track all transfer rumors on the map →
   transfer-map.com
   
   #TransferNews #Football #Transfers #HereWeGo
   #[리그명] #[선수명] #[클럽명]
   ```
   - 영문으로 작성 (타겟이 해외 풋볼 팬)
   - 캡션 첫 줄이 핵심 — 팬이 스크롤하다 멈출 정보
   - 링크는 Instagram bio에 고정 (본문 링크는 클릭 안 됨)

3. **해시태그**
   - 고정: `#TransferNews` `#Football` `#Transfers` `#HereWeGo`
   - 상황별 추가: `#PremierLeague` `#LaLiga` `#Bundesliga` `#SerieA` `#Ligue1`
   - 선수/클럽명 태그 추가 (검색 유입)
   - 해시태그는 30개 이하로 — 과하면 스팸 처리

4. **업로드**
   - 게시물 형식: 단일 이미지
   - 스토리에도 동일 이미지 + "New post" 스티커로 리포스팅

### Reddit

#### 스텝

1. **서브레딧 선택**
   - 해당 이적과 관련된 리그 서브레딧 우선 (`r/PremierLeague`, `r/laliga` 등)
   - `r/soccer`는 규모 크지만 경쟁 심함 — 화제성 높을 때만
   - `r/transfers`는 항상 가능

2. **포스팅 전 준비**
   - 해당 서브레딧 규칙 확인 (셀프 프로모션 제한 있는 경우 있음)
   - 게시 전 며칠간 댓글 활동으로 계정 신뢰도 확보 (없으면 스팸 필터 걸림)

3. **제목 작성**
   - 도구 소개형: `I built an interactive map to track European football transfer rumors in real-time`
   - 이적 뉴스 연계형: `Mapped out all the summer transfer rumors so far — here's what it looks like`
   - 광고성 단어 금지: "Check out", "Visit my site" 같은 표현 → 삭제 위험

4. **본문 작성**
   ```
   Been tracking transfer rumors on an interactive map for the past few months.
   You can filter by league, club, or player — and see which clubs are most active this window.
   
   Site: transfer-map.com
   
   Happy to take feedback or feature requests in the comments!
   ```
   - 자연스러운 쇼케이스 톤 유지
   - 댓글 유도 문장 포함 (Reddit 알고리즘은 댓글 수로 노출 결정)
   - 본문에 스크린샷 이미지 첨부 (텍스트만이면 반응 적음)

5. **댓글 관리**
   - 올린 후 2~3시간은 댓글 모니터링하며 빠르게 답글
   - 피드백은 감사히 받고 기능 개선에 반영 → 신뢰 구축

### Twitter/X

#### 스텝

1. **프로필 세팅** (최초 1회)
   - Bio: `⚽ Football transfer news & rumors on an interactive map | transfer-map.com`
   - 링크: transfer-map.com
   - 프로필 이미지: 로고 또는 맵 아이콘

2. **트윗 작성**
   - 이적 속보 연계형:
     ```
     [선수명] to [클럽명] is now CONFIRMED on the map 🔴
     
     Check all active transfer rumors →
     transfer-map.com
     
     #TransferNews #HereWeGo #Transfers
     ```
   - 주기적 근황 공유형:
     ```
     Summer window is heating up 🔥
     
     [X] confirmed transfers, [Y] active rumors tracked on the map right now.
     
     transfer-map.com
     
     #Transfers #TransferNews
     ```

3. **이미지**
   - 맵 스크린샷 반드시 첨부 (이미지 있는 트윗이 2~3배 노출 유리)
   - Twitter는 16:9 비율이 잘 보임

4. **기자 멘션 전략**
   - Fabrizio Romano, David Ornstein 등 이적 기자 트윗에 맵 링크 댓글
   - 직접 멘션은 자제 (스팸으로 인식될 수 있음) — 대신 해당 트윗 스레드에 참여

## 체크리스트 — 게시 전

- [ ] 스크린샷에 해당 이적/루머가 명확히 보이는가
- [ ] 캡션/제목에 선수명, 클럽명이 포함되어 있는가
- [ ] 사이트 링크가 포함되어 있는가
- [ ] 해시태그가 적절한가 (과하지 않게)
- [ ] 광고성 문구가 없는가 (Reddit 특히 주의)
- [ ] 이적 상태(루머/확정)가 정확히 표시되어 있는가
