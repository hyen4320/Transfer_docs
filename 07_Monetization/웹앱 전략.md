# TransferMap 웹앱 전략

## 현재 완성도

| 영역 | 상태 |
|------|------|
| FE | 80% — 메인맵, 뉴스피드, 기자 랭킹, 선수 상세, 모바일 대응 진행 중 |
| BE | 30% — 도메인/레포지토리 완료, 서비스 로직·컨트롤러 미완 |
| DB | 50% — 리그/구단 데이터 적용, 선수/이적 데이터 미완 |
| Infra | 0% — Docker/배포 미설정 |

---

## 완성까지 예상 기간 (솔로 작업 기준)

| 작업 | 예상 기간 |
|------|----------|
| BE Service 로직 + Controller | 3~4주 |
| DB 데이터 완성 (kaggle, 크롤러) | 1주 |
| X API 수집 파이프라인 | 1~2주 |
| FE 모바일 최적화 + 버그 수정 | 1~2주 |
| Infra — Docker + 배포 + HTTPS | 1주 |
| 테스트 + 안정화 | 1주 |
| **합계** | **8~11주** |

### MVP 단축 전략
X API 수집 없이 mock/정적 데이터로 먼저 배포하면 **4~5주**로 단축 가능.
수익 발생 여부 확인 후 X API 파이프라인 추가하는 게 리스크 낮음.

---

## 수익 모델

### 1. Google AdSense (현재 진행 중)
- 승인 대기 중
- 트래픽 기반 수익 — 방문자 수에 비례
- 이적 시즌(1월, 6~8월)에 트래픽 급증 예상
- 예상 수익: 월 DAU 1,000명 기준 월 $10~30 / DAU 10,000명 기준 월 $100~300

### 2. 프리미엄 구독
무료/유료 기능 분리

| 무료 | 유료 ($3~5/월) |
|------|----------------|
| 이적 뉴스 피드 | 이적 알림 (특정 선수/구단) |
| 지도 시각화 | 기자 공신력 상세 분석 |
| 기자 랭킹 | 히스토리 무제한 조회 |
| | 광고 제거 |

### 3. 제휴 마케팅
- 스포츠 스트리밍 서비스 (ESPN+, DAZN 등) 제휴 링크
- 스포츠 용품 브랜드
- ⚠️ 베팅 사이트는 AdSense 정책 위반 가능 — 제외

### 4. 데이터 API 판매
- 이적 데이터 API를 외부 개발자/미디어에 판매
- 트래픽과 데이터 신뢰도가 충분히 쌓인 후

### 5. 스폰서십
- 풋볼 분석 툴, 스카우팅 회사 등 틈새 스폰서
- DAU 수천 명 이상 달성 후 현실적

## 우선순위 로드맵

```
지금       AdSense 승인 대기 + sitemap 제출
4~5주 후   MVP 배포 (BE API + 정적 데이터)
배포 후    Reddit/Twitter 마케팅 → 트래픽 확보
트래픽 후  프리미엄 구독 도입 여부 판단
장기       데이터 API, 스폰서십
```

## 핵심 리스크

| 리스크 | 대응 |
|--------|------|
| X API 비용/제한 | MVP는 X API 없이 배포, 수익 확인 후 추가 |
| 이적 시즌 외 트래픽 급감 | 비시즌에도 볼 수 있는 콘텐츠 확보 (역대 이적 히스토리) |
| AdSense 수익 낮음 | 프리미엄 구독을 보조 수익으로 병행 |
