# AdSense 거절 원인 분석

## 거절 항목 요약

구글이 지적한 항목은 두 가지다:

1. **복제된 콘텐츠가 있는 화면에 Google 게재 광고**
2. **가치가 별로 없는 콘텐츠**

---

## 실제 사이트 구성

뉴스피드는 기사 본문/이미지를 스크래핑하는 게 아니다.  
X(트위터) 기자 게시물 기반으로 **구조화된 데이터**를 표시한다:

- 선수명, 이적 클럽 (from → to)
- 이적료, 이적 상태 (RUMOUR / CONFIRMED / DENIED / LOAN)
- 기자 이름, 신뢰도 점수, 원본 링크 (View on X →)

본문 텍스트나 이미지를 복사해서 붙여넣는 구조가 아님.

---

## 왜 거절됐는가

### 핵심 원인: 구글 크롤러가 읽을 텍스트가 없다

TransferMap은 **데이터 시각화 도구(tool/dashboard)** 다.  
구글 입장에서 페이지를 크롤링하면:

- 지도 → SVG/Canvas, 크롤러가 내용 파악 불가
- 뉴스 카드 → 선수명 + 숫자 + 상태 배지, 텍스트 거의 없음
- 저널리스트 테이블 → 이름 + 점수, 설명 없음

**사람이 직접 쓴 문장이 사이트 어디에도 없다.**  
구글은 이를 "내용이 빈약한 콘텐츠"로 판단한다.

### "복제된 콘텐츠" 항목이 나온 이유

정확한 이유는 불명확하다. 구글 자동 심사 시스템이 어떤 기준으로 이 항목을 띄웠는지 알 수 없다.  
다만 두 항목(복제 콘텐츠 + 가치 없는 콘텐츠)은 같은 근본 원인에서 나왔을 가능성이 높다 — **사이트에 독자적인 텍스트가 없다**는 것.

---

## 핵심 문제

AdSense는 **콘텐츠 사이트(블로그/미디어)** 기준으로 심사한다.  
도구형 사이트가 통과하려면 **직접 작성한 텍스트 콘텐츠**가 별도로 있어야 한다.

---

## 해결 방향 (우선순위 순)

### A. 사이트 고유 텍스트 콘텐츠 추가 (핵심)

아래 중 하나 이상 구현:

- **이적 분석 글**: "2025 여름 이적시장 트렌드", "리그별 지출 비교" 등 직접 작성 (최소 10개)
- **선수 프로필 페이지**: 이적 히스토리 타임라인 + 텍스트 설명
- **리그 이적 리포트**: 시즌별 리그 요약 (반자동 생성 가능)

→ 구글 크롤러가 읽을 수 있는 고유 텍스트를 만들어야 함

### B. About / 서비스 소개 페이지 보강

현재 About이 있다면 내용을 구체화 (서비스 목적, 데이터 출처, 운영자 정보).  
없다면 신설.

### C. 개인정보처리방침 점검

AdSense 쿠키 조항이 포함되어 있는지 재확인.

---

## 재심사 시 체크리스트

- [ ] 직접 작성한 텍스트 콘텐츠 최소 10개 이상 추가
- [ ] About 페이지 운영자 정보 / 서비스 설명 구체화
- [ ] 개인정보처리방침 AdSense 쿠키 조항 포함 확인
- [ ] Search Console에서 새 콘텐츠 색인 확인 후 재심사 요청

## 참고

- 재심사: AdSense 콘솔 → "사이트 검토 요청" 버튼

- 같은 이유로 재거절되면 콘텐츠 분량/품질을 더 높인 후 재요청
